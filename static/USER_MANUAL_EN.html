BOP Piping Progress Dashboard

Version: v16 | Project: CCGT BOP Piping Extension

1. Overview

The BOP Piping Progress Dashboard is an enterprise-grade construction management tool designed to monitor fabrication and erection progress in real-time. It processes over 47,000 joint records to provide accurate KPIs and predictive planning metrics.

2. Getting Started

  • Access: Navigate to http://localhost:5000/?v=v16
  • Initial Build: The server uses high-speed background threads to pre-calculate progress. If you see a loading screen, the system is performing a full audit of all database records.

3. Data Entry (Joint Master)

Actual Date Input

We have optimized the date entry for constructor speed. You can now use the short format:

YY-MM-DD (Example: 26-03-29)

The system will automatically recognize the year 20XX and update the database accordingly.

Bulk Updates

  1. In the search bar, type the ISO No.
  2. Enter the date in the blue panel.
  3. Click Apply to All to update every spool in the ISO drawing instantly.

4. Weekly Planning

Use the Week Plan tab to schedule priority ISO drawings. This module allows you to set specific DI Targets for individual weeks, which are then compared against real-world progress in the Weekly Productivity charts.

5. Exporting to Excel

Our dashboard uses the File System Access API. When you click Export Excel:

  1. A standard Windows "Save As" window will open.
  2. Choose your destination folder and filename.
  3. The data is exported in native .xlsx format, compatible with MS Excel 2016 and later.
Pro Tip: Use the Refresh button at the bottom of the left sidebar if you suspect the KPI summary doesn't reflect a very recent edit. It forces the server to purge its cache and rebuild the statistics from scratch.
